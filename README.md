# Storyer Scripts

Open source scripts and automation tools for customer support leaders.
Built from real support ops work — practical, self-hosted, no subscriptions.

Full documentation and setup guides at **[storyer.dev](https://storyer.dev)**

---

## Scripts

### Zendesk

| Script | Description | Docs |
|---|---|---|
| [zendesk-attachment-remover](./zendesk-attachment-remover/) | Auto-redacts attachments from closed tickets. Standalone PHP or WordPress plugin. | [storyer.dev/scripts/zendesk-attachment-remover](https://storyer.dev/scripts/zendesk-attachment-remover/) |
| [zendesk-ticket-closer](./zendesk-ticket-closer/) | Let customers close their own tickets via a one-click link in email. | [storyer.dev/scripts/zendesk-ticket-closer](https://storyer.dev/scripts/zendesk-ticket-closer/) |
| [zendesk-web-form](./zendesk-web-form/) | Drop-in PHP contact form that creates Zendesk tickets without API keys. | [storyer.dev/scripts/zendesk-web-form](https://storyer.dev/scripts/zendesk-web-form/) |
| [zendesk-auto-merge](./zendesk-auto-merge/) | Automatically merges duplicate tickets from the same requester in real time. Runs on Google Cloud Run. | [storyer.dev/scripts/zendesk-auto-merge](https://storyer.dev/scripts/zendesk-auto-merge/) |
